Features

不止是翻译，是一套完整的字幕工作流

从音频捕获到最终导出，RTT 把每个环节都打磨到位，让你专注观看，而不是折腾工具。

系统 / 麦克风双来源

默认捕获 YouTube、网课、直播与本地播放器的系统音频；也可切换麦克风输入，用于会议与口语练习，支持粤语。

Apple 端侧识别

基于 macOS 26 SpeechAnalyzer，语音识别在本机完成，低延迟且保护隐私；并内置 Apple Translation 可选设备端引擎。

Bing 在线翻译

识别结果经 Bing 翻译为简体中文，翻译失败可单句重试，稳准兼顾。

置顶悬浮窗

独立窗口置顶显示，可切换原文/译文，锁定后防止误拖动与误缩放。

低延迟预览

句子完成前即可看到临时翻译，完成后替换为正式双语字幕，所见即所得。

字幕样式模板

默认 / 黑底 / 透明 / 学习四种模板，适配不同视频背景，看清每个字。

VAD 长静音断句

内置语音活动检测，长静音时强制断句，避免一句拖得太长、译文迟迟不来。

转写浏览器

会话内集中回看本次全部字幕记录，按完整句子生成正式记录与滚动预翻译。

多格式导出

一键导出双语 SRT、TXT 或 Markdown；可复制当前字幕或最近几条字幕。

语言灵活切换

翻译过程中切换识别语言，不会清空已完成字幕，模型下载进度可见、完成自动开始识别。

术语表改译

自定义关键术语的固定译法，避免专有名词被误翻。

应用内自动更新

菜单栏检查更新，默认每天自动检查一次；Sparkle 校验更新包完整性。

How it works

四步，从声音到字幕

声音进入 Mac，文字浮现眼前。整条链路在本地与云端之间精准衔接。

01 / CAPTURE

捕获音频

授予屏幕录制权限后，RTT 抓取系统音频流；也可选麦克风用于会议口语。

02 / RECOGNIZE

设备端识别

Apple SpeechAnalyzer 在本机完成语音转文字，首用某语言需下载模型。

03 / TRANSLATE

实时翻译

识别结果发送至 Bing，译为简体中文；先有预览，后有正式译文，失败可重试。

04 / DISPLAY

悬浮窗呈现

双语字幕在置顶窗口显示，可锁定、换样式、复制、导出。

Get started

装好即用，几行命令跑起来

普通用户直接从 Releases 下载 DMG 拖入 Applications；开发者可从源码构建。

Terminal
# 1. 安装 GNU Awk 及其运行库（仅源码构建需要）
brew install gawk

# 2. 开发模式直接运行
swift run RTT

# 3. 构建带固定 Bundle ID 的 App
./scripts/build-app.sh
open dist/RTT.app

# 4. 运行测试
swift test
  • macOS 26.0 或更高Apple Silicon Mac，Silicon 原生运行
  • Swift 6.2+用于本地构建与开发
  • GNU Awk 5.4.1由 Homebrew 安装，供翻译组件调用
  • 屏幕录制权限用于捕获系统音频
  • 网络连接Bing 翻译与首次下载语音模型需要联网

权限与隐私，透明为先

系统音频由 RTT 捕获，语音识别在本机由 Apple SpeechAnalyzer 完成；识别文字仅发送至 Bing 用于翻译。RTT 不保存任何音频文件，导出的字幕也只包含已完成的原文与译文，不包含仍在变化的临时识别内容。
